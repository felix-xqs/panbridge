# 云桥 PanBridge

面向国内用户的多网盘同步工具。

云桥将本地目录与一个或多个云端目录连接起来，提供接近系统云盘的使用体验：文件变更自动上传或下载，支持断点续传、冲突保留和同步状态查看。

## 目标

- 本地目录与云端目录双向同步
- 通过统一适配器接入百度网盘、夸克网盘、WebDAV 等服务
- 断网、限速、暂停后可以继续同步
- 双端同时修改时保留冲突文件，不静默覆盖
- 凭证保存在系统安全存储中

## 设计方向

项目由同步引擎、网盘适配器和桌面客户端组成。同步状态使用 SQLite 保存，核心引擎与 CLI、桌面客户端解耦。

首个可用版本计划先支持本地目录和 WebDAV，用于验证同步引擎；之后再接入具有稳定接口的国内网盘服务。

## 项目状态

项目刚创建，当前处于设计和基础设施阶段。

已实现本地扫描和只读初次合并预览，包含流式列举、SQLite 临时索引、CPU 节流和资源统计。自动上传下载、历史基线和后台监听仍在开发路线中。macOS 与 Windows 是首发目标。

## 运行验证版

需要 Go 1.23 或更新版本。

```bash
go build -o ./bin/panbridge ./cmd/panbridge

./bin/panbridge scan --root "/path/to/local-folder"

./bin/panbridge dry-run \
  --left "/path/to/local-folder" \
  --right "/path/to/another-folder"
```

默认以单核 25% 为 CPU 平均目标进行协作式节流，输出耗时和进程峰值内存。可用 `--cpu-budget 10` 进一步降低占用，或 `--cpu-budget 0 --scan-pause 0` 测量吞吐。该设置控制扫描与预览阶段的平均负载，不保证瞬时上限。

`dry-run` 输出初次合并建议：独有文件列为待复制，同名差异需要确认，文件/目录冲突及链接不会被自动处理。元数据匹配不代表内容已校验。当前命令只读取选定目录；SQLite 索引在系统临时目录创建并在完成后清理。

加 `--json` 可输出机器可读数据；`dry-run` 输出逐行 JSON，最后一行汇总，默认最多显示 50 条计划，可用 `--limit 0` 只输出统计。

可复现的测试数据和测量方法见 [性能验证说明](docs/validation.md)。
